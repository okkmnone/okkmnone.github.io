Liner notes

A player that is not yet a file.

Rust 1.100.0 went stable on 12 November 2026. This page is a small film about how it got there, and a working demonstration of what the browser can and cannot record.

Rust 1.100.0 is the first stable release whose minor version has three digits. The number looks like a rupture. It is the opposite. From 1.0 on 15 May 2015 to 1.100.0 is one hundred steps on a six-week train, a little over eleven years, without a Rust 2. Incompatible ideas were absorbed as editions — 2015, 2018, 2021, 2024 — so old crates keep compiling. One hundred is a milestone, not a migration guide.

The headline of this particular train is a single character. The never type, spelled !, is stable after ten years and five failed attempts. It is the type of computations that do not produce a value: return, break, exit. Because a value of that type cannot exist, Rust will coerce it into whatever type the surrounding code was waiting for. Infallible is now an alias of !. That was the plan from the day Infallible was introduced, and it is why the stabilization took a decade. There is a narrow break: on editions before 2024, never-type fallback now resolves to ! rather than the unit type. Rare, real, and warned about for years. The official announcement points to a talk by contributor waffle for the trouble along the way.

Also on this train

Not only a type

The core of the allocator API is stable. Box and Vec can carry a custom allocator without nightly. Not every collection — the foundation, not the whole house. DropGuard runs a closure on every exit path and can be dismissed when the work commits. conjure_zst is the blessed, still unsafe, way to materialize a zero-sized value. Cargo grows its own lint table, including unused dependencies, and a minimum publish age: dependency cooldowns. A newly published crate can be asked to wait. Smaller print includes bool::toggle, Vec::from_fn, trim prefix and suffix, map on Box, Rc, and Arc, extern "custom", wasm32-wasip3 at tier 2, Unicode 18 in the standard library, and — quietly — a tier 3 target for the PlayStation 3.

How this reel is made

      

        

          
There is no stock footage and no external image. Every frame is drawn into a 1280×720 canvas, which is also the bitmap an export encodes. What you watch and what you can file are the same picture. The crab in the corner is an original geometric mark, not the official Ferris artwork. Ferris remains the community’s unofficial mascot — a ferric joke on a language named for a fungus.

          
Narration is the Web Speech API, window.speechSynthesis. That is the standard browser text-to-speech surface. It is not an audio element and it is not a Web Audio node. In Microsoft Edge, the same API exposes online neural voices, typically named like “Microsoft Aria Online (Natural) — English (United States)”. Those are the cloud voices behind Read Aloud. This page lists English voices only, and if it is running in Edge it ranks the online ones first. Other browsers get the best English voice they actually have: a Google English voice, a macOS Samantha, a local Windows voice. A non-English default is never selected. If an online voice errors, the player falls back once to a local English voice and says so. If there is no English voice at all, the picture, the captions, and the score still run.

          
The platform catch, and it is a platform catch: speechSynthesis does not return samples. canvas.captureStream() cannot hear it. An AudioContext cannot tap it. So a button labeled “record the player” cannot honestly promise that an Edge online voice will be inside the MP4. This page does not call unofficial Edge speech sockets to get around that. The online service is reached the way the platform intends — by selecting an online English voice and calling speak.

          
Pause returns to the start of a line, with a short rewind so the limitation is visible. Seek previews any frame, then snaps to a sentence when the voice starts. That is not a stylistic preference. The speech API has no sample offset. Lines are kept short on purpose: some engines stop firing events if a single utterance runs too long, so the reel is a chain of sentences rather than one monologue.
